# pi extensions — moved

This repository is archived. The extensions now live in
**[pnettto/pi-agent-config](https://github.com/pnettto/pi-agent-config)**, together with
prompts, themes, safe defaults, and setup/publication checks.

```sh
git clone https://github.com/pnettto/pi-agent-config.git ~/.pi/agent
python3 ~/.pi/agent/scripts/setup.py --apply
```

See its `SHARING.md` if `~/.pi/agent` already exists.
